# Data Collect
Папка в которой собраны все скрипты для собирания всей информации с демок
- demo_parser.py: Парсинг всех фичей из демки
- pos_matching.py: Матчинг позиций игроков из демки с миникартой на радаре #TODO доделать радар (чтобы было более похоже на настоящий)
- screen_capture.py: Автономная запись экрана демки
- video2frames.py: Перевод записанного видео из screen_capture в кадры с матчингом радара из pos_matching
- dataset_collect.py: Полный сбор датасета в формате json с кадрами из video2frames, фичами из демки и сопоставленными радарами
# Src
Папка в которой собрана архитектура модели
- Dataset.py: Формирование датасета
- Dataloader.py: описание сэмплера для данных
- RadarEncoder.py: Архитектура для обработки радара, представляет собой EfficientNetB0 обрезанный до 5 блока
- Yolo.py: Детектор на основе Yolo11n и энкодер эмбеддинга полной сцены на фичах из p3 уровня yolo
- TemporalTransformer.py: Описание архитектуры временного трансформера, который предсказывает следующее действие на основе текущих и предыдущих состояний мира
- Train.py: Скрипт обучения
# Image Parse
Папка в которой содержатся парсинг фичей с изображений, нужно для этапа инференса
# Tamplates
Папка с шаблонами изображений для сравнения с целевыми, используется в Image Parse
